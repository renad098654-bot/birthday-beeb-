# Birthday Surprise — جاهز للنشر

هذا موقع عيد ميلاد تفاعلي ثابت (HTML/CSS/JS) ويعمل بدون قاعدة بيانات.

## الملفات
- `index.html` — كل صفحات التجربة.
- `style.css` — التصميم المتجاوب.
- `script.js` — التفاعلات والأقفال والأسئلة والكيكة والموسيقى.
- `assets/childhood.jpg` — صورة الطفولة التي تم إدراجها في الأسطوانة.
- `assets/song.mp3` — اختياري: ضعي هنا ملف الصوت الذي تملكين حق استخدامه حتى تعمل الأغنية داخل الموقع.
- `.github/workflows/deploy.yml` — نشر تلقائي على GitHub Pages.

## الأكواد
- Gift 02: يقبل إجابات تتضمن كلمات مرتبطة بالتهديد (لأن الإجابة الأصلية الدقيقة لم تُحدد).
- Gift 05: `1214`

## الموسيقى
إذا أضفتِ `assets/song.mp3` سيظهر مشغل صوت صغير، وعند الضغط على الأسطوانة تدور وتعمل الأغنية داخل الموقع.
إذا لم يوجد الملف، الضغط على الأسطوانة يفتح رابط TikTok المرفق في الطلب.

ملاحظة: لا تضعي ملف أغنية لا تملكين حق استخدامه. يمكنك استخدام ملف صوتي تملكينه أو لديك إذن لاستخدامه.

## نشره كرابط
أسهل خيار: GitHub Pages.
1. أنشئي مستودعًا جديدًا على GitHub.
2. ارفعي محتويات هذا المجلد كما هي (خصوصًا `index.html` و`assets`).
3. Settings → Pages → Build and deployment → اختاري النشر من `main`.
4. سيعطيك GitHub رابطًا عامًا للموقع.

يوجد أيضًا workflow جاهز داخل `.github/workflows/deploy.yml` إذا أردتِ النشر عبر GitHub Actions.
